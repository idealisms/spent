# Dependency upgrade status

Tracks the major-version dependency upgrades for `tracker/`. Started after
adding the Puppeteer e2e test suite (#145) gave a safety net (build + 89
unit tests + a real-browser render) to upgrade against.

Each group below landed as its own PR, verified with: `tsc --noEmit`,
`yarn test`, `yarn build`, `yarn test:e2e` (plus `eslint app` before
ESLint was removed).
